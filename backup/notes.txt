Direct API Endpoints

If you want to fetch data programmatically without relying on a third-party GitHub mirror, users on Reddit's r/remotesensing community note that you can query the official DeepStateMap API directly:
• Fetch Available Timestamps. Send a GET request to https://deepstatemap.live to retrieve a JSON list of historical update IDs and timestamps.
• Download Specific GeoJSON. Append a specific update ID from that list to https://deepstatemap.live<id>/geojson to download the raw GeoJSON feature collection for that exact date.

Data Structure & Usage Notes

• Coordinate System. All standard GeoJSON feeds from these sources use the WGS84 (EPSG:4326) coordinate reference system, making them directly compatible with QGIS, Leaflet, Mapbox, and Python's geopandas library.
• Zone Classification. Depending on the endpoint, features are typically categorized by status (such as occupied territory, Crimea/ORDLO, liberated areas, and contested/gray zones needing clarification).
