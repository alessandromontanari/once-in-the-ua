# Once in the UA

The country code for Ukraine, "UA", comes from the country's official name in Ukrainian: "Україна" (Ukraïna).

Слава Україні! Героям слава!

## Why this repo and the interactive website?

In March 2022, when Russia commenced its full-scale invasion of Ukraine, I suddenly became more aware that many injustices were still plaguing humanity. And another one had just started. Trying to contribute in any way I could to fight this injustice, I thought I could write an interactive website to summarise the events that, over the last couple of decades, culminated in the biggest war fought in Europe since WWII.

In the hope that history will not be forgotten.
