# Once in the UA

The country code of Ukraine, "UA", is derived from the official name of the country in Ukrainian: "Україна" (Ukraïna).
Слава Україні! Героям слава!

## Why this repo and the interactive website?

In March 2022, when Russia commenced its full-scale invasion of Ukraine, I suddenly became more aware that there many injustices were still plaguing humanity. And another one had just started. Trying to contribute with all the possible means to figth this injustice, I thought I could write an interactive website to summarise the events that, in the last couple of decades, culminated in the biggest war ever fought in Europe since WWII.
In the hope that history will not be forgotten.
